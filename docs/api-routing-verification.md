# التحقق من روابط API قبل النقل

اختار المستخدم تأجيل النقل للحفاظ على عدم الانقطاع. المنفذ 3000 متاح من خارج الخادم، وسجل التطبيق الحالي لا يحفظ Host. لا يمكن استنتاج عنوان الربط المضبوط لدى كل جهة من مجرد نجاح الجاهزية أو أسماء الحسابات.

## الأداة

`scripts/exportApiRoutingChecklist.cjs --candidate <candidate-folder> --source <serving-folder>` تقرأ دليل الشركات والوكلاء من MongoDB باستعلامين محدودين، دون تشغيل التطبيق أو العمال أو تغيير الحسابات. تشمل الحسابات النشطة التي فُعّل API لها أو يوجد لها مفتاح حديث/قديم؛ وجود المفتاح يُختبر داخل الاستعلام ولا تُعاد قيمته أو بصمته. القائمة لا تثبت وجود استخدام حالي، ولا تعيد تفعيل حساب مقفل.

تُحفظ أسماء الحسابات ومراجعها في CSV محلي داخل مجلد عشوائي جديد في `runtime-routing-review`. تتحقق الأداة على Windows من DACL محمي يقتصر على المستخدم المشغّل وSYSTEM وAdministrators قبل كتابة البيانات، وترفض الإكمال عند فشل التحقق. ملف CSV مُحيّد لصيغ الجداول ومُستبعد من Git بواسطة قاعدة `*.csv`. لا تطبع الأداة أسماء الحسابات أو مفاتيحها أو أرصدتها في تقرير JSON.

فحص Flutter اختياري ومحدود بملفات Dart في مجلد المصدر: 200 ملف، عمق 8، و5 MiB إجمالًا مع استبعاد البناء والاختبارات والروابط الرمزية. يعيد أصل URL ومسار ملف الشيفرة فقط، ويحذف معلومات الدخول والمسار والاستعلام من URL المعروض. عناوين الشيفرة ليست إثباتًا لعناوين التطبيق الموزع.

## المطلوب من المراجعة

1. افتح CSV على الخادم. عمود `expected_base_url` مأخوذ من أصل PUBLIC_APP_URL/APP_URL السليم، وهو توصية وليس القيمة المضبوطة لدى العميل.
2. املأ `verified_client_base_url` من إعدادات الربط الفعلية لدى الشركة/الوكيل، مع اسم المراجع وتاريخ التأكيد. دوّن الأصل والمنفذ ومسار API فقط، دون username/password أو query أو مفاتيح.
3. راجع كذلك التطبيق المحمول ومنفذي التنفيذ وأي خدمة داخلية أو جهة تتصل بالمنفذ مباشرة؛ كشف الحسابات لا يغطي هذه الجهات تلقائيًا.
4. أرسل ملخص الأصول والمنافذ وعدد الجهات التي تأكدت منها. لا حاجة لإرسال ملف الأسماء أو التوكنات أو بيانات مالية.

كل الصفوف غير مؤكدة عند التصدير، و`allClientUrlsVerified=false` دائمًا حتى المراجعة البشرية. إذا ظهر `truncated=true` فالقائمة جزئية. لا تغيير لوجهة الموقع أو المفاتيح أو الجدار الناري بمجرد إنشاء الملف أو العثور على عنوان في Flutter.
