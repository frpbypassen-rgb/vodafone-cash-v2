مراجعة بوابة التنفيذ — 25 أكتوبر 2026

المشروع: executor-service-queues
الحالة: تحديث بوابة التنفيذ، لم يُنشر على سيرفر الإنتاج.

نطاق المراجعة
تسجيل الدخول والجلسات وMFA، صلاحيات الأدوار والمجموعات، العمليات والإثباتات،
الأرصدة والمجمعات، الموظفون، التقارير، الإيداعات، الإعدادات، الدعم، وتنظيم ملفات الواجهة.

الإصلاحات
1. توحيد التحقق من الجلسة والحساب والمجموعة وإصدار الجلسة في middleware واحد.
   إغلاق تجاوز شرط استكمال MFA في مسارات المدير والتقارير، مع رد JSON واضح لطلبات API.
2. حصر صلاحية تنفيذ المهام بالأدوار المسموح بها صراحة، وقصر عرض إثباتات المرسل الخاصة على مدير المجموعة.
3. استكمال حقول الخدمة وعضوية مجمع الرصيد في استعلامات GET، دون تحميل بيانات الاعتماد السرية.
4. منع تفسير استجابة HTML أو JSON غير صالح على أنها نجاح عند استدعاء API من الواجهة.
5. الاحتفاظ بملفات الإثبات عند عدم التأكد من نتيجة commit في MongoDB؛ إرجاع حالة واضحة
   تطلب التحقق من العملية قبل إعادة المحاولة، بدلاً من حذف إثبات قد يخص عملية محفوظة فعلاً.
6. إصلاح عدم عرض الحالة الفارغة في محادثة الدعم.
   وضبط ارتفاع المحادثة على الهاتف كي لا يغطي شريط التنقل أسفلها جزءاً من حقل الإرسال.
7. الحفاظ على كلمة المرور كما أدخلها المستخدم عند تسجيل الدخول، بما يشمل المسافات الطرفية،
   لتتطابق مع سياسة حفظ كلمات المرور في التسجيل والإعدادات.

التنظيم والصيانة
- فصل سكربتات الإعدادات والإيداعات والدعم في ملفات page.js مستقلة ومغلقة النطاق.
- فصل تنسيق صفحة الإعدادات والحفاظ على ترتيب تحميل السكربتات والأنماط.
- تأمين إدراج اسم الموظف داخل بيانات JavaScript ضد إغلاق وسم script.
- تحديث توثيق هيكل البوابة ومسؤولية الملفات والأوامر اللازمة لفحصها.
- إضافة npm run check:executor لتشغيل lint والتنسيق وسياسة المعمارية وTypeScript واختبارات البوابة.
- تحديد الاختبارات بأسماء الملفات، وتجهيز أسرار تجريبية معزولة، لمنع تشغيل مجموعة غير مقصودة.

حدود التحقق
- نجح npm run check:executor كاملاً: 57 مجموعة اختبار، و642 اختباراً، دون إخفاق.
  نجحت فحوص ESLint والتنسيق وسياسة المعمارية وTypeScript ضمن الأمر نفسه.
- اختبار Chrome شمل 22 حالة محلية لصفحات الإعدادات والإيداعات والدعم، عبر أربعة أدوار
  حسب صلاحية الصفحة، وبعرضي 390 و1440 بكسل. بيانات وواجهات API تجريبية.
- اختبارات المعاملات تستخدم MongoDB تجريبية محلية، ولا تنفذ تحويلات لدى المزوّد الحقيقي.
- شُغّلت اختبارات المتصفح باستخدام Chrome المثبت محلياً وتحديد PUPPETEER_EXECUTABLE_PATH؛
  نسخة Chrome الافتراضية التي يتوقعها Puppeteer غير مثبتة في ذاكرة التخزين المؤقت لهذا الجهاز.
- فحص TypeScript يخص حدود src الحالية، وليس جميع ملفات JavaScript في المشروع.
- لا تمثل هذه المراجعة ضماناً لانعدام جميع الأخطاء أو اختباراً فعلياً لنسخة الإنتاج.

ما بقي للتحسين التدريجي
- تقسيم دالة عرض مهام لوحة التحكم الكبيرة وتقليل المتغيرات العامة ومعالجات HTML المضمنة.
- توحيد تجاوزات CSS المشتركة يحتاج مراجعة بصرية مستقلة؛ لم يُخلط مع إصلاحات التنفيذ الحالية.
- تظهر تحذيرات Mongoose عن الخيار القديم new في اختبارات قائمة؛ تستلزم ترحيلاً منفصلاً
  إلى returnDocument بعد مراجعة الاستدعاءات المتأثرة.

الأدلة
ملفات الأدلة التالية محفوظة محلياً في مجلد outputs لمساحة العمل:
- executor-portal-final-check.log: مخرجات أمر الفحص الشامل للبوابة.
- executor-portal-review/browser-results.json: نتائج حالات Chrome وقياسات عرض الصفحات.
- executor-portal-review/*.png: صور صفحات محلية ببيانات تجريبية.
- ../executor-service-queues/docs/executor-portal-structure.md: توثيق الهيكل والصيانة.
