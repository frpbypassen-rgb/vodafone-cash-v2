# توثيق محاسبة الوكالة وهوامش العملاء

تاريخ الاختبار: 7 أغسطس 2026  
قاعدة البيانات: MongoDB 8.3.2 مستقلة بدون Replica Set

## السيناريو المالي

- هامش العميل: 3 قروش، أي فرق سعر صرف بقيمة 0.03.
- سعر الوكالة للكاش: 6.40، وسعر العميل النهائي: 6.37.
- مثال 1,000 EGP: تكلفة الوكالة 156.250 LYD، وتكلفة العميل 156.986 LYD، والربح 0.736 LYD.
- تحصيل 50 LYD رفع رصيد العميل من 500.000 إلى 550.000، مع إيصال وقيد دفتر متوازن.
- التحويل `ATT-2608-0001` خصم قيمة العميل وقيمة الوكالة كل واحدة بصورة مستقلة، ثم تحوّل إلى ناجح بالمرجع `E2E-REF-260807-01`.
- سحب 500 LYD سمح بوصول الحساب إلى رصيد سالب، وظهر دين بقيمة 106.986 LYD في شاشة الديون.
- سداد جزئي بقيمة 50 LYD خفّض الدين إلى 56.986 LYD وسجّل حركة سداد مستقلة.
- اختبار الإلغاء `ATT-E2E-CANCEL-001` أعاد 47.096 LYD للعميل و46.875 LYD للوكالة بالكامل، وولّد رقم الإلغاء `CAN-2608-00004` وإيصال إلغاء عربياً.
- كل قيود وكالة الاختبار متوازنة: إجمالي المدين يساوي إجمالي الدائن.
